ПОРТФОЛИО — как залить на сайт

1. Открой index.html, найди блок CONFIG (в самом низу, в <script>) и впиши свои контакты:
   Telegram, почта, ВК. Там же можно переименовать категории.
2. Залей ВСЮ папку site как есть (index.html, data.js, папку works) на любой хостинг статики:
   - Netlify Drop (app.netlify.com/drop) — просто перетащи папку, ссылка сразу;
   - GitHub Pages; Vercel; Beget/Timeweb — в корень сайта.
3. Новая работа = новая папка в works/... + запись в data.js (по образцу остальных).
   Раздел «Монтаж видео»: у работы ставь "cat": "video", в media кидай {"t":"video","src":"..."}.
4. Локально index.html открывается двойным кликом — всё работает без сервера.
