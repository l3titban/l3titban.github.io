ПОРТФОЛИО l3titban

- Контакты: index.html → блок CONTACTS в <script> внизу (Telegram, почта, ВК).
- Работы: data.js. Каждая работа: id, cat (cards / 3d / sites / video / mascots), title, tag, text, cover, media[], по желанию ba (было/стало) и wb (ссылка).
- Новая категория-заглушка «скоро» заполняется сама, как только в data.js появятся работы с её cat.
- Фон с горами из точек: bg.js (three.js).
